# Codex Float

Last updated: `2026-09-30T22:27:07+08:00`

在官方 Codex App 中照常启动和使用任务，悬浮窗自动展示本机任务的模型、推理强度、子代理关系和运行情况。无需在新窗口重新输入任务。

应用从本仓库 `float/` 构建，输出为 `build/Codex Float.app`。

## 0.5.0 本轮用量与可追溯路由

- 设置增加“整个任务 / 当前轮次”；右侧保持大号 token 数，本轮模式显示本轮参考费用，累计模式保留额度节省与比例。
- 数字账本持久保存在 `~/.codex/adaptive-router/usage.sqlite3`，重启、日志轮换和超过 4096 请求仍可去重累计。账本仅含线程/请求标识、数字用量、价格 hash 和读取位置，不保存任务正文或推理。
- 详细视图显示路由选择依据、个人偏好与 accepted/rejected/unknown 验收状态。显式新轮次事件及时覆盖滞后的旧索引状态。
- 共享 router 的本地模型/价格快照；Float 每分钟检查本地更新，运行时不联网。每个请求保持首次计量价格，更新费率不会改写历史。
- 评分、计量、比价与界面刷新均为本地规则和算术，不额外请求模型。公开目录的刷新由 router 完成。

## 0.4.0 自动参考节省与 6.1 Sol

- 默认“自动额度对比”：用真实已计量请求对比同量全部使用 Astra 的 Standard 参考额度，显示“折合省 数量（比例）”。无需填写缩减比例。
- 数量单位明确为 **Astra 等价 tokens**，表示价格差的等价额度，不是实际少生成的 token。主任务节省含可见子代理；右上累计 token 仍仅属该任务自身。部分计量与待计量分别标记，未知价格不会算免费。
- 手动数量试算保留在设置的另一个模式，原有参数不会被自动模式覆盖。
- 新增 GPT-6.1 Sol 参考费率：普通输入/输出与 GPT-6 Sol 相同，缓存输入为其一半。新路由优先将中等工作与普通复杂工作交给 6.1 Sol，架构、高风险、连续失败诊断继续用 Astra。

## 使用

1. 打开 Codex Float。窗口默认置顶，官方 Codex 的本机任务会自动出现，每 2 秒刷新。
2. 选择 **简略 / 标准 / 详细**。简略显示模型、难度和累计 token；标准增加片段参考费用与自动等价节省；详细增加输入/缓存/输出/推理、来源、目录和“在 Codex 打开”。
3. **活跃**显示进行中与待确认任务；**最近**显示最近 8 个主任务；**全部**显示所有未归档主任务。可搜索标题、模型或目录。主任务下的子代理按关系排列，可整体折叠。
4. 拖动标题栏移动，拖动边缘缩放。右上角显示设置可切换小/中/大窗口、文字缩放与玻璃背景透明度；图钉控制置顶。窗口位置、尺寸和显示偏好会记住。
5. 关闭窗口会隐藏它。用菜单栏 Codex Float 图标重新显示、重新连接或退出。退出不会影响官方 Codex 的任务。

## 数据的含义

- **模型与推理强度**来自官方 App 的本机任务元数据，是任务设置；没有报告的字段显示“未报告”。这不是逐 token 的服务端模型遥测。
- **运行情况**来自最近轮次记录。已完成、已中断和出错分别显示。未结束轮次超过 3 分钟没有新事件时显示“待确认”，长时间工具调用也可能进入这个状态；不把旧记录永久当作正在运行。
- **最近事件**只显示事件或工具类型，不展示推理正文、对话正文、工具参数或文件内容。它表示最近记录，不代表当前正在执行该步骤。
- 累计 token 为该任务在 Codex 元数据中的记录，包含上下文消耗，可能比日志略晚更新。当前片段按逐请求 usage 去重，输入包含缓存、输出包含推理。主子任务各自显示；这些计数不是订阅账单。
- 当前接入本机 Codex 数据；远程主机和 ChatGPT 普通聊天不在监视范围。未启动过轮次的任务可能显示“未知”。

## 接入方式

只读打开 `~/.codex/state_5.sqlite`、`thread_history_1.sqlite` 和桌面任务标题目录；旧格式任务使用有上限的增量事件读取。`CODEX_HOME` 环境变量可指定其他本机数据目录。数据库以 `mode=ro` 和 `query_only` 打开。

这个版本监视官方 App 已经启动的任务，不启动第二套 App Server、不接管任务、不自动改模型或档位。无需 API key，也不发起模型推理或网络请求。官方 App 目前没有在本机开放已验证的共享控制 socket，因此没有把独立引擎的状态冒充成官方 App 的状态。

任务简介只在本地内存参与规则评分，不出现在监视输出，也不另存或发送；其余对话、推理正文和工具正文均不显示。价格来自已验证本地目录并带内置回退，评分和计量没有模型调用。官方数据库始终只读；Float 仅写自己的数字账本与显示偏好。

数据格式属于本机版本的内部实现，Codex 更新可能需要调整适配器；缺失或读取失败会明确显示，不会修改数据库修复。当前已对本机 Codex 数据验证。官方 App Server 协议依据：[OpenAI Docs](https://learn.chatgpt.com/docs/app-server)。

## 构建与验证

需要 macOS 14+、`/usr/bin/python3`，构建需要 Xcode 命令行工具。应用为本机 ad-hoc 签名。

```sh
cd float
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 scripts/sync_router.py --source ../router
sh scripts/build.sh
```

后端测试覆盖：原有监视功能、请求去重、父任务历史排除、缓存/推理子集、模型切换、未知价格、日志轮换、分段/大行读取、只读路径范围、评分桥接、简介不外露和轮次索引延迟。真实本机 286 个任务/子代理，后端冷读取约 126 毫秒，热刷新约 16 毫秒，测试进程约 25 MiB（本次测量）。

显示偏好保存在 macOS UserDefaults（`io.github.chengjun023.codex-float`），不额外保存任务正文或事件副本。没有开机自启动、HTTP监听或全局快捷键。上一版 Codex Router 保留；adaptive-router 已单独升级为动态难度路由。

原生窗口实测：官方 App 活动主任务与新子代理自动出现，三级详细程度、窗口预设大小、字号和屏幕边界通过。0.3.0 时30秒交互采样窗口RSS峰值116.5MiB，CPU峰值10.2%、末点0%；先前懒布局循环已修复。父窗口退出后监视器自动退出已验证。
